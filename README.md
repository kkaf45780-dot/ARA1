# ARA — Universal Floating Translator

**عالمك، بلغتك.**

تطبيق أندرويد عربي أصلي (Kotlin + Jetpack Compose + Material 3) يحوّل الترجمة إلى طبقة عائمة فوق أي تطبيق: التقط الشاشة، استخرج النص محلياً، ترجم إلى العربية، واعرض النتيجة دون مغادرة ما تقرأه أو تلعبه.

> **الحالة:** `0.1.0-mvp` — الكود مكتمل على مستوى الوحدات، و**تم تجميع نسخة التطوير بنجاح** (`assembleDebug`) واجتاز Lint (0 أخطاء)، لكنه **لم يُشغَّل بعد على جهاز أو محاكي**. راجع [docs/LIMITATIONS.md](docs/LIMITATIONS.md) قبل أي استخدام جاد.

---

## أبرز الميزات

- **أيقونة عائمة حقيقية** فوق التطبيقات: سحب، تثبيت على الحافة، حجم، شفافية، إيقاف مؤقت، وتذكّر الموضع.
- **التقاط شاشة رسمي** عبر `MediaProjection` بموافقة صريحة لكل جلسة، مع احترام `FLAG_SECURE`.
- **تحديد منطقة** لترجمة جزء محدد فقط.
- **OCR محلي** عبر ML Kit: لاتيني، صيني، ياباني، كوري، وهندي (Devanagari).
- **OCR عربي اختياري** عبر Google Cloud Vision، مع بوابة خصوصية تمنع الإرسال إذا أوقفت «إرسال الشاشة إلى السحابة».
- **4 مزوّدات ترجمة** قابلة للتبديل:
  - ML Kit محلي (دون إنترنت بعد تنزيل النموذج).
  - Google Cloud Translation v2.
  - LibreTranslate (بما فيها الاستضافة الذاتية).
  - أي خدمة متوافقة مع OpenAI (ترجمة سياقية/أدبية).
- **ثلاثة أساليب:** حرفية، طبيعية، أدبية (تؤثر فعلياً على المزوّد الذكي).
- **مشاريع ومصطلحات:** قاموس لكل مشروع، تصنيفات للشخصيات والأماكن والمهارات، وملاحظات قصة تُمرَّر كسياق.
- **عرض فوق النص:** ترجمة سطرية فوق النص الأصلي في نافذة غير معترضة للمس.
- **سجل وذاكرة مؤقتة** لتقليل الطلبات المتكررة.
- **ترجمة صور/مانهوا** مع تجميع تقريبي لأسطر الفقاعات، **قاموس شخصي**، **مساعد ذكي**، **مكتبة TXT/EPUB/PDF** وقارئ، و**وضع ألعاب**.
- **إدخال صوتي** عبر `SpeechRecognizer` الرسمي مع تفضيل النموذج المحلي، و**نطق TTS** لنتائج الترجمة والكلمات.
- **بحث شامل** في القاموس والسجل والمشاريع والكتب.
- **مفاتيح API مشفّرة** داخل Android Keystore — لا مفاتيح في الكود.
- **عربي أولاً، RTL، وضع داكن افتراضي.**

### ما لا يعمل بعد

- **تشغيل فعلي على جهاز/محاكي** — لم يُختبر بعد (الجهاز المتاح عليه 4GB RAM فقط).
- **OCR عربي محلي دون إنترنت** — ML Kit لا يوفّر نموذجاً عربياً؛ البديل السحابي الاختياري.
- **كشف فقاعات حقيقي بالرؤية الحاسوبية** — الموجود تجميع تقريبي لأسطر النص داخل الصورة.
- **توقيع الإصدار ورفع Google Play** — يحتاج مفتاح توقيع خاص بك.
- **اختبارات آلية وCI** — لم تُضف بعد.
- **توطين إنجليزي كامل وقاعدة بيانات مشفّرة** — خارج نطاق MVP الحالي.

كل ما هو غير منفّذ فعلاً يظهر بوضوح ولا ينفّذ نجاحاً وهمياً.

## التشغيل السريع

### 1. فتح المشروع

1. افتح Android Studio.
2. `File → Open` واختر مجلد `ARA`.
3. انتظر مزامنة Gradle. سينزّل SDK 35 وتبعيات Compose/ML Kit تلقائياً إن لم تكن موجودة.
4. إن ظهرت رسالة عن `local.properties`، أضف مسار SDK:

```properties
sdk.dir=C\:\\Users\\<USER>\\AppData\\Local\\Android\\Sdk
```

### 2. البناء من سطر الأوامر (اختياري)

```powershell
cd "C:\Users\This PC\Documents\ARA"
.\gradlew.bat :app:assembleDebug
```

> إذا فشل اتصال Kotlin daemon على ويندوز، أعد المحاولة مع تجميع داخل عملية Gradle:
>
> ```powershell
> .\gradlew.bat :app:assembleDebug --project-prop "kotlin.compiler.execution.strategy=in-process"
> ```

أو التثبيت مباشرة على جهاز/محاكي متصل:

```powershell
.\gradlew.bat :app:installDebug
```

ملف APK المتوقع:

```text
app/build/outputs/apk/debug/app-debug.apk
```

### 3. أول تشغيل

1. امنح **«الظهور فوق التطبيقات»** من مركز الصلاحيات.
2. اسمح بالإشعارات (Android 13+) لرؤية إشعار الخدمة وزر الإيقاف.
3. من الشاشة الرئيسية اضغط **«تفعيل الأيقونة العائمة»**.
4. افتح أي تطبيق، ثم اضغط الأيقونة:
   - نقرة واحدة: قائمة الأدوات.
   - نقرة مزدوجة: الإجراء المضبوط (افتراضياً ترجمة الشاشة).
5. عند أول ترجمة ستظهر نافذة موافقة التقاط الشاشة الرسمية.

## إعداد مزوّد الترجمة

افتح **الإعدادات ← مزوّد الترجمة**، واختر المزوّد ثم أدخل بياناته واضغط **«حفظ المفاتيح والإعدادات»**. استخدم **«اختبار المزوّد»** للتحقق قبل الاستخدام.

| المزوّد | ما يحتاجه | ملاحظات |
|---|---|---|
| **ترجمة محلية (ML Kit)** | لا شيء | نزّل نموذجي العربية والإنجليزية من **الإعدادات ← الموارد دون اتصال**. يعمل دون إنترنت بعد ذلك. |
| **Google Cloud Translation** | مفتاح API | فعّل `Cloud Translation API` في Google Cloud. |
| **LibreTranslate** | عنوان الخدمة (+ مفتاح اختياري) | مثال: `https://libretranslate.example.com`. يمكن استضافته ذاتياً لحفظ الخصوصية. |
| **ترجمة بالذكاء الاصطناعي** | مفتاح + Base URL + اسم النموذج | أي خدمة متوافقة مع OpenAI Chat Completions. الافتراضي `https://api.openai.com/v1` و`gpt-4o-mini`. |

### المساعد الذكي (اختياري)

**الإعدادات ← المساعد الذكي** له مفتاح وعنوان ونموذج مستقلان عن مزوّد الترجمة. يُستخدم للشرح والتلخيص وتحليل النبرة/الشخصيات وتفاصيل القاموس. لا يُستدعى تلقائياً؛ كل طلب بضغطة.

### OCR عربي اختياري (Google Cloud Vision)

 ML Kit لا يدعم العربية. إذا أردت ترجمة نص عربي من الشاشة أو صورة أو PDF ممسوح:

1. فعّل `Cloud Vision API` في مشروع Google Cloud وأصدر مفتاح API.
2. افتح **الإعدادات ← OCR عربي (اختياري)** وألصق المفتاح ثم اضغط **«حفظ مفتاح OCR»**.
3. فعّل **«السماح بإرسال الشاشة إلى السحابة»** من إعدادات الخصوصية.
4. اختر لغة المصدر **العربية** قبل الالتقاط.

> عند إيقاف بوابة السحابة لا تُرسل أي صورة إلى Google حتى لو وُجد المفتاح. الخدمة قد تفرض تكلفة، وتُرسل الصورة كاملة إلى Cloud Vision.

### الإدخال الصوتي والنطق

- **الصوت**: من قائمة الأدوات العائمة، أو امنح صلاحية الميكروفون من **مركز الصلاحيات** أولاً. نطلب من `SpeechRecognizer` تفضيل النموذج المحلي (`EXTRA_PREFER_OFFLINE`)؛ إذا لم يتوفر نموذج لغة محلي فقد يعرض النظام خطأً بدلاً من إرسال الصوت سحابياً.
- **النطق**: زر «استماع» في لوحة الترجمة وزر «نطق» في بطاقة الكلمة يستخدمان محرك TTS المثبّت على الجهاز. لا نضمّن محركاً خاصاً.

### أين تُحفظ المفاتيح؟

- المفاتيح تُشفَّر بـ AES-256/GCM داخل **Android Keystore** ولا تُكتب في الكود أو المستودع.
- حذف الحقل يحذف المفتاح من الجهاز.
- عنوان الخدمة واسم النموذج يُحفظان في SharedPreferences عادية (ليست أسراراً).
- النسخ الاحتياطي معطّل (`allowBackup=false`).

## الخصوصية والصلاحيات

| الصلاحية | الاستخدام |
|---|---|
| `SYSTEM_ALERT_WINDOW` | الأيقونة العائمة فوق التطبيقات |
| `FOREGROUND_SERVICE` + `SPECIAL_USE` | بقاء خدمة المساعد |
| `FOREGROUND_SERVICE_MEDIA_PROJECTION` | خدمة التقاط الشاشة |
| `POST_NOTIFICATIONS` | إشعار دائم وزر إيقاف |
| `RECORD_AUDIO` | الإدخال الصوتي فقط عند استخدام أداة الصوت |
| `INTERNET` / `ACCESS_NETWORK_STATE` | المزوّدات السحابية والذكاء الاصطناعي وOCR السحابي الاختياري |
| موافقة `MediaProjection` | تُطلب من نافذة النظام لكل جلسة |

**لا يطلب التطبيق:** تخزين عام، كاميرا، أو AccessibilityService. ولا يستخدم Root. صلاحية الميكروفون اختيارية ولا تُطلب إلا عند فتح أداة الصوت.

### بوابة «إرسال الشاشة إلى السحابة»

عند إيقاف **الإعدادات ← الخصوصية ← السماح بإرسال الشاشة إلى السحابة**:

- أي ترجمة مصدرها الشاشة أو منطقة محددة تُفرض عليها الترجمة المحلية، حتى لو كان المزوّد النشط سحابياً.
- بطاقة شرح الكلمة في المساعد العائم ترفض الإرسال وتوضّح السبب.

هذا الخيار **ليس مفتاح قطع شبكة عاماً**؛ المحادثة اليدوية وترجمة الصور المختارة صراحةً قد تستخدم السحابة إذا اخترت ذلك.

## التحقق والاختبار

**آخر تحقق (9 نوفمبر 2026):**

| الفحص | النتيجة |
|---|---|
| `:app:assembleDebug` | ✅ ناجح — APK بحجم ~136 MiB (142,784,745 بايت) |
| `:app:lintDebug` | ✅ ناجح — 0 أخطاء، 11 تحذيراً غير حاجز |
| ترجمة/بحث/TTS/صوت في الكود | ✅ مبنية، تحتاج تحققاً يدوياً |
| تشغيل على جهاز/محاكي | ⛔ لم يحدث بعد |
| اختبارات آلية | ⛔ لا توجد |

أعد البناء محلياً بـ:

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

ثم اختبر يدوياً:

1. منح/سحب صلاحية الظهور.
2. موافقة التقاط الشاشة ثم إلغاؤها ثم إعادتها.
3. ترجمة شاشة كاملة ومنطقة محددة.
4. كل مزوّد بمفتاح صحيح وآخر خاطئ.
5. تطبيق بـ `FLAG_SECURE` (يجب ألا يُكسر).
6. إيقاف «إرسال الشاشة للسحابة» مع مزوّد سحابي.
7. إعادة تشغيل التطبيق وبقاء الموضع والسجل والمشاريع.

قائمة الاختبار الكاملة في `docs/ARCHITECTURE.ar.md` (القسم 20).

## استكشاف الأخطاء

| المشكلة | السبب المحتمل | الحل |
|---|---|---|
| لا تظهر الأيقونة | صلاحية الظهور مسحوبة أو الخدمة أُوقفت | مركز الصلاحيات ← منح الصلاحية، ثم إعادة التشغيل |
| «لم أجد نصاً واضحاً» | `FLAG_SECURE` أو نص صغير/عربي | جرّب منطقة أدق أو صورة أوضح؛ للعربية فعّل Cloud Vision واختر المصدر العربية |
| «OCR لهذه اللغة يحتاج السحابة» | لغة المصدر عربية وبوابة السحابة مغلقة | فعّل إرسال الشاشة للسحابة + مفتاح Vision، أو اختر لغة يدعمها ML Kit |
| EPUB لا يُستورد | DRM أو ملف ليس EPUB صالحاً | استخدم EPUB بدون حماية؛ الرسالة توضح السبب |
| PDF لا يُستورد | محمي بكلمة مرور أو صور غير واضحة | جرّب PDF نصي أو صورة أوضح؛ OCR السحابي يساعد للعربية |
| الصوت لا يعمل | صلاحية الميكروفون أو لا يوجد نموذج محلي | امنح الصلاحية من مركز الصلاحيات وثبّت حزمة لغة للتعرف دون اتصال |
| فشل الترجمة المحلية | النموذج غير منزّل | الإعدادات ← الموارد دون اتصال ← تنزيل عربي/إنجليزي |
| فشل المزوّد السحابي | مفتاح/عنوان/شبكة | «اختبار المزوّد» ثم راجع الرسالة |
| اختفت الأيقونة بعد فترة | توفير بطارية من المصنّع | اسمح بالعمل في الخلفية من إعدادات النظام |
| انهيار عند أول بناء | SDK/JDK غير مطابق | JDK 17 + SDK 35 + Android Studio Ladybug+ |
| فشل Kotlin daemon | مشكلة اتصال محلية على ويندوز | أضف `--project-prop "kotlin.compiler.execution.strategy=in-process"` |
